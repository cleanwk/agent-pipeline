# Author Pipelines through intent, not a visual editor

Pipeline 创建和修改采用 AI-native 交互：用户用自然语言、现有 Skill 或业务资料表达意图，模型负责生成结构化 Change Proposal，Host App 负责渲染 Graph、协议 Diff、权限变化、验证和测试结果，并在用户确认后应用。Graph Projection 支持观察、导航、展开、筛选和版本对比，但不提供拖拽连线或 Dify 式低代码编排；产品价值在于让模型完成配置劳动，同时让人清楚理解并控制结果。
