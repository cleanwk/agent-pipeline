# Use ACP as a baseline with native Runtime enhancements

Runtime Adapter 以 ACP 提供跨 Codex、Claude Code、OpenCode 和 Pi 的基础会话、事件与能力协商，但 ACP Session 不进入核心领域模型，且最低公共接口不限制产品能力。Codex App Server、OpenCode 原生服务、Claude 官方适配器和 Pi RPC 等结构化能力可作为原生增强，PTY 只用于兼容与诊断；Onboarding 与节点 UI 必须如实显示每个 Runtime 的恢复、审批、MCP 和结构化进度能力。
