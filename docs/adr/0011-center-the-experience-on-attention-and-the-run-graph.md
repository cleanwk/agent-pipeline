# Center the experience on Attention and the Run Graph

Host App 启动后首先回答“哪些任务在运行，哪里需要我”，以跨 Run 的 Attention Queue 和活跃运行作为 Mission Control，而不是展示配置或最近文件。进入 Pipeline Run 后，Graph Projection 是主舞台，承载当前路径、节点状态、反馈环和可展开 Activity；选择任意 Node 可沿 Node Run、Attempt、Agent Session、Activity、工具、变更和 Artifact 逐层进入 Node Focus，返回后保持原 Graph 的位置与时间上下文。Run Brief、Deliverables、Timeline 与 Node Inspector 提供其他下钻视角。人工介入汇入 Attention Queue，并通过 Graph、系统通知和专用 Review Surface 到达，不用全局模态框劫持用户工作。
